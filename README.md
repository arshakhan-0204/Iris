# Iris
🌸 **Iris Flower Classification**  ✨ A Machine Learning project that classifies Iris flowers into three species: Setosa, Versicolor, and Virginica using sepal and petal measurements.  🤖 **Key Features:** - 📊 Data Analysis &amp; Visualization - 🌱 Feature Selection - 🎯 Model Training &amp; Prediction - 📈 Accuracy Evaluation
